05 / THE METHOD

A useful clue, not a verdict.

Sampling profiles are estimates. A change in share tells you where to investigate, then you repeat the workload to confirm it.

01

Capture comparably

Record the same user action or benchmark before and after a change. Different inputs, warmup, or recording lengths can alter the ranking.

02

Match the source

Frames match by function name, URL, line, and column. The tool sums sample intervals for each top frame and excludes profiler idle and internal markers.

03

Read the trade-off

Share is relative to sampled function time, not wall-clock CPU usage or a statistical confidence claim. Use the milliseconds and source locations as context.
